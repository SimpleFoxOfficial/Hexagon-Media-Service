Setting up HDRezka

HDRezka blocks anything that is not a real browser.

1

Install the app

Run the file you just downloaded.

The folder is always here:

%LOCALAPPDATA%\Programs\Hexagon Media Service\resources\extension
2

Open your browser's extensions page

Copy the address below into the address bar.

chrome://extensions

Then turn on Developer mode.

3

Load the folder

Press Load unpacked and choose the folder.

Pick the folder itself, not a file inside it.

4

Copy the pairing token from the app

Open the app, go to Download, then HDRezka.

The token is what stops any web page you visit from talking to the app.

5

Paste it into the extension

Open the extension's options and paste the token.

It should say Connected.

Using it

Open any film or series on HDRezka in your browser and leave the tab open.

If something does not work

The app says the extension is not connected
Copy the token again.
Could not establish connection
Reload the HDRezka tab once.
This does not look like an HDRezka title page
Open the film or series itself first.
The extensions page will not open from a link
Copy the address and paste it in yourself.

The manual covers the rest.
