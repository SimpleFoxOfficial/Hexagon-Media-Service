Hexagon Media Service
================

A private, local media downloader. Nothing is uploaded, no account is required,
and every setting stays on this machine.


What gets installed
-------------------

  * Hexagon Media Service        the application and its interface
  * mediadl-engine.exe      the bundled download engine, used automatically

Settings, logs and download history are written to:

  %APPDATA%\MediaDownloader

They are kept when you uninstall, so reinstalling restores your setup. Delete
that folder by hand if you want a clean slate.


What it needs
-------------

  * ffmpeg, to merge video with audio and to convert audio formats. If it is
    not on your PATH, set its location in Settings. Without it, downloads that
    need merging will fail.

  * Google Chrome or Microsoft Edge, only if you intend to use HDRezka. That
    part needs the companion browser extension, which is documented in the
    manual.

Nothing else is required. Python does not need to be installed; the engine is
bundled.
